# Pruneo

Free up space on your iPhone and Mac.

**On iPhone**, Pruneo finds exact duplicates, similar and blurry photos, screenshots, heavy videos and Live Photos. You review them by swiping: left deletes, right keeps. Photos never leave your iPhone.

**On Mac**, Pruneo shows what takes space, labels every item and moves everything to a Quarantine first, so any cleanup can be undone. The Mac app is free.

- Website: https://pruneo.app/en/?ref=github
- iPhone: https://apps.apple.com/app/apple-store/id6827276314?pt=118750683&ct=github&mt=8
- Mac (Homebrew): `brew install --cask leanvitale/tap/pruneo`
